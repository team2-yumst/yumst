# yumst 😋

🍽 나만을 위한 완벽한 맛집 추천!
매번 "뭐 먹지?" 고민하는 당신을 위해, 가장 정확하고 취향에 맞는 맛집 추천을 제공합니다!
수치 기반 분석과 AI 추천 시스템을 활용해, 더 이상 실패 없는 맛집 탐방을 경험해보세요.

📌 주요 기능
🔹 AI 기반 맞춤 맛집 추천
당신의 취향과 과거 기록을 분석해, 좋아할 만한 맛집을 똑똑하게 추천합니다.
단순한 평점이 아니라, 당신의 선호 패턴을 분석하여 최적의 선택을 제공합니다.

🔹 수치 기반 맛집 추천
사용자와 맛집의 다양한 데이터를 활용해 가장 신뢰할 수 있는 맛집을 알려드립니다.
특별한 날 가고 싶은 맛집, 혼자 음식에 집중할 수 있는 맛집, 조용히 집중할 수 있는 카페, 분위기까지 맛있는 카페 등
다양한 상황에 맞는 추천을 제공해, 원하는 순간에 가장 적합한 장소를 찾을 수 있습니다.
숫자로 보는 객관적인 추천이 필요할 때, 이 기능을 활용하세요!

🔹 위치 기반 식당 선호 투표
내 주변 맛집 중 어디가 더 인기 있을까?
사용자들이 직접 참여하는 선호 투표 기능을 통해, 실제 사람들의 의견을 확인하고 트렌디한 맛집을 찾아보세요!

🍴 이제 고민하지 말고, 한 번에 딱 맞는 맛집을 찾으세요!
당신만을 위한 완벽한 맛집 추천 서비스, 지금 바로 다운로드하고 시작하세요! 🚀
